# 2026-05-19 Pipeline Retrieval And Enrichment

Keep enough corpus budget for long music pages, but let MusicBrainz override structured release data where it is stronger than prose sources.

Search results should rank Wikipedia ahead of low-signal sources, then fetch more non-Wikipedia pages when no Wikipedia result is available. This prevents sparse current-release pages from producing generic editorial copy.

Artist, project, track, and label edges should be enriched from MusicBrainz when an MBID can be resolved. MB is the canonical source for discographies, tracklists, label metadata, artist credits, dates, and tags that lag or drift in editorial pages.
