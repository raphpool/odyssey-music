# 2026-05-19 Groundedness

When source material is thin, the model may invent scalar fields or edge names from disambiguator text. Canonicalization must drop ungrounded label values and suspicious tracklist entries before schema validation.

Citations must come from the retrieved corpus or search results. If the model emits invalid citation URLs while corpus pages exist, the pipeline fills citations from the fetched pages instead of persisting an empty citation list.
